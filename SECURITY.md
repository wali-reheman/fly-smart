# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | ✅ All features    |

## Reporting a Vulnerability

If you discover a security issue, please report it via:

**Email**: wali@nju.edu.cn

Do **not** open a public GitHub issue for security vulnerabilities. Please give us reasonable time to address the issue before disclosing it publicly.

Include as much detail as possible:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

We aim to respond within 48 hours and will provide a timeline for a fix.
